# 5-Day AI Agents Intensive Course with Google x Kaggle

This repository contains my practice notebooks from the 5-Day AI Agents Intensive Course, crafted by Google's ML researchers and engineers.

## About the Course

This intensive online course explores the foundations and practical applications of AI agents, helping developers move beyond LLM prototypes to production-ready systems. The course covers core components including models, tools, orchestration, memory, and evaluation through a blend of conceptual deep dives, hands-on examples, codelabs, and live discussions.

## Course Structure

### Day 1: Foundations
- **day-1a-from-prompt-to-action.ipynb** - From Prompt to Action
- **day-1b-agent-architectures.ipynb** - Agent Architectures

### Day 2: Tools
- **day-2a-agent-tools.ipynb** - Agent Tools
- **day-2b-agent-tools-best-practices.ipynb** - Agent Tools Best Practices

### Day 3: Sessions & Memory
- **day-3a-agent-sessions.ipynb** - Agent Sessions
- **day-3b-agent-memory.ipynb** - Agent Memory

### Day 4: Observability & Evaluation
- **day-4a-agent-observability.ipynb** - Agent Observability
- **day-4b-agent-evaluation.ipynb** - Agent Evaluation

### Day 5: Advanced Topics
- **day-5a-agent2agent-communication.ipynb** - Agent-to-Agent Communication
- **day-5b-agent-deployment.ipynb** - Agent Deployment

## How the Course Works

- **Daily Content Release**: New assignments posted daily on the Kaggle course page
- **Assignment Notifications**: Materials shared on Kaggle Discord and via email
- **Support & Discussion**: Dedicated Discord channels with Google researchers and engineers
- **Daily Livestreams**: Live sessions at 11 AM PT / 8 PM CET / 12:30 AM IST on Kaggle's YouTube channel
- **Flexible Learning**: Complete assignments at your own pace
- **Capstone Project**: Final day project to apply learned concepts and earn a Kaggle badge
